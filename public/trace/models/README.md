# u2netp.onnx

U²-Net, small version ("u2netp", 4.7 MB), for finding the main subject in a photo.

- Model and weights: Xuebin Qin et al., "U²-Net: Going Deeper with Nested U-Structure for Salient Object Detection" (Pattern Recognition, 2020), https://github.com/xuebinqin/U-2-Net, Apache-2.0.
- ONNX export: from rembg (https://github.com/danielgatis/rembg, MIT), release v0.0.0 `u2netp.onnx`, SHA-256 below.

Used by `../photo.js` for My Animals. It runs on the device; photos are never uploaded for this.
